# Material de estudio — Centrales hidroeléctricas

Empieza por `Guia_de_estudio_Centrales_Hidroelectricas.pdf`; usa el DOCX si quieres tomar notas o adaptar el plan. El Markdown es la versión fuente.

La guía propone una ruta de ocho semanas, resúmenes por disciplina, fórmulas, ejercicios resueltos, problemas de práctica y autoevaluación. La dedicación de 5–6 horas semanales es una sugerencia que puedes ajustar al sílabo y al tiempo disponible.
